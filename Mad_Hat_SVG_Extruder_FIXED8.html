01 · IMPORT ARTWORK

Best results: SVGs made from filled, closed shapes. Text should be converted to paths in your vector editor first.

02 · MODEL DIMENSIONS

Changing the default thickness updates every shape. You can then fine-tune each shape using its own slider below.

03 · SVG GROUPS & SHAPES

Click a shape in the preview or a shape row to select its entire imported SVG. The bounding box surrounds all shapes from that SVG. Hold Ctrl while clicking the preview or rows to select multiple SVGs.

Load an SVG to see its shapes here.
04 · EXPORT MODEL

Separate STL export creates one STL per imported SVG, preserving that SVG's shapes, holes and individual thicknesses. Multiple files download one after another; allow downloads if your browser asks.

STL does not store colour. Use OBJ + MTL for compatible 3D tools. The separate STL exports retain each SVG's placement relative to the combined model; they are not automatically moved to the origin.
